# web-tools

Small static web tools, published with GitHub Pages. The root `index.html` is a landing page that links to each tool.

## Tools

- [Date Offset Calculator](date-offset-calculator/) — add Critical / High / Medium day offsets to a start date.

## Adding a tool

1. Create a folder for it containing an `index.html` (self-contained, no build step).
2. Add a link and short description to the root `index.html`.
3. Add it to the list above.
4. Commit and push to `main`. Pages redeploys automatically.
